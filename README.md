# Лабораторна робота №3: TDD (варіант 9)

Модуль розрахунку вартості оренди за принципом Red–Green–Refactor.

## Умови
- Базова ставка: 800 грн/доба.
- 1–6 діб: знижка 0%.
- 7–29 діб: знижка 10% на всю вартість оренди.
- Від 30 діб: знижка 25% на всю вартість оренди (не сумується з 10%).
- Поворотна застава: 2000 грн, вноситься при отриманні, повертається після повернення об'єкта.
- Тривалість: додатне ціле число діб; помилка `INVALID_DAYS` для інших значень.

## Запуск
```sh
npm ci
npm test
npm run test:coverage
npm run typecheck
```

## Функції
- `calculateRentalCharge(days)` — вартість оренди з урахуванням знижки.
- `calculateUpfrontPayment(days)` — платіж при отриманні з заставою.
- `calculateRentalSummary(days, { returned?: boolean })` — деталізація платежу, повернення застави й кінцевих витрат.

Коміти `red:`, `green:`, `refactor:` створено в послідовності TDD. Перевірте `git log --oneline --reverse`.
