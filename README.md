# Лабораторна робота №4 — Тестові дублери та MSW (варіант 9)

Частина 1: `OrderService`, заглушки, шпигуни, фейкове сховище, контроль часу, `withRetry`, HTTP-провайдер курсів, MSW.

Частина 2: черга надсилання повідомлень (3 спроби, пауза 2000 мс). Реалізовані інтерфейси `MessageRepository`, `MessageGateway` і перевірки обох видів відмов. Реальні мережеві запити в тестах блокує MSW (`onUnhandledRequest: 'error'`).

## Запуск

```sh
npm install
npm test
npm run coverage
npm run typecheck
```

У `tests/` наведені приклади і самостійний варіант. Впровадження залежностей через конструктор дозволяє тестувати без доступу до реального API. Бібліотеки потрібні для запуску Vitest/MSW, Node.js 20+.

Звіт містить результати, пояснення й контрольні питання. Рецензію на реальну роботу однокурсника та посилання на власний GitHub-репозиторій потрібно доповнити після їх отримання.
